账号配置会加密后存成 admin.txt 放在仓库里，里面是 GitHub 令牌和阅读口令。设置好后点最下面的按钮，会自动上传到仓库，不用你手动传。

2. 阅读口令（网站解锁用的那个）

2. 阅读口令（网站解锁用的那个）

3. GitHub 令牌（可留空，留空则只能下载不能自动发布）

必须用 Fine-grained token：GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → 只勾选 shanshu-videos 这一个仓库 → Permissions 里把 Contents 设为 Read and write → 生成后复制。
