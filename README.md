# 抖音视频笔记 · 检索站

把 Word 笔记变成一个可在手机上检索的离线网站：**40 万字、208 篇**，精准搜索 + 模糊搜索，支持补充自己的内容，日间夜间一键切换。

纯静态站点，无后端、无数据库，所有检索在浏览器本地完成，可断网使用。

**笔记内容以 AES-256-GCM 密文存放**，需输入访问口令才能解锁，搜索引擎和不持有口令的人只能拿到乱码。

## 目录结构

```
.
├── index.html          页面结构
├── app.css             样式（日间/夜间双主题，靠 CSS 变量切换）
├── app.js              搜索、索引、补充内容、解密、PWA 逻辑
├── sw.js               Service Worker（离线缓存）
├── manifest.json       PWA 配置（可添加到主屏幕）
├── icons/              应用图标
├── data/
│   ├── index.enc       目录与摘要密文（约 100 KB，首屏加载）
│   └── full.enc        全文与表格密文（约 1.3 MB，后台加载）
└── tools/
    ├── parse_docx.py   从 Word 重新生成明文数据的脚本
    └── encrypt.mjs     把明文数据加密成 .enc 的脚本
```

> `data/index.json`、`data/full.json` 是明文中间产物，已被 `.gitignore` 排除，**不要推送到仓库**。

## 本地预览

项目必须经 HTTP 打开（直接双击 index.html 会因浏览器安全限制读不到数据）：

```bash
cd 项目目录
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 更新笔记内容

改完 Word 后重新生成数据，并**重新加密**（口令可以换，也可以沿用）：

```bash
pip install python-docx
python3 tools/parse_docx.py 你的文档.docx -o ./data
node tools/encrypt.mjs "你的口令"
```

文档需使用 Word 的**标题样式**：`标题 1` 对应年份分章，`标题 2` 对应每一篇，`标题 3` 对应小节。目录区会自动跳过。

## 加密与访问口令

- **算法**：PBKDF2-HMAC-SHA256（60 万轮，随机盐）派生密钥 + AES-256-GCM 加密，两个数据文件共用同一个盐，各自使用独立随机 IV。
- **口令不上传**：口令只在你自己的设备上参与密钥派生，从来不会发送到服务器，也没有任何地方保存口令本身。
- **忘记口令**：重新跑一遍 `parse_docx.py` + `encrypt.mjs` 即可，笔记原文在你自己手上，不会因口令丢失而丢失。
- **改口令**：用新口令重跑 `encrypt.mjs`，重新部署。所有设备下次打开时需要输新口令。
- **记住 30 天**：勾选后会把一个**不可导出**的密钥对象存进 IndexedDB（取不到原始密钥字节），30 天有效；顶栏会出现 🔒 按钮，可随时锁定。
- **防爬**：线上只有密文，爬虫拿到的是二进制乱码；页面同时带 `noindex`，不会被搜索引擎收录。

> 加密不是万能的：若口令强度太低，有人拿到密文后仍可能暴力破解。建议 8 位以上、字母与数字混合。

## 部署

任何静态托管都能放，几个常用选择：

| 平台 | 国内访问 | 费用 | 说明 |
|---|---|---|---|
| 腾讯云 EdgeOne Pages | 快 | 免费额度 | 可从 GitHub 仓库一键导入，推荐国内使用 |
| GitHub Pages | 不稳定 | 免费 | 服务器在境外，国内打开看运气 |
| Vercel / Netlify | 一般 | 免费 | 有被干扰的风险 |
| 任意对象存储（OSS/COS） | 快 | 几元/月 | 需实名，绑自定义域名要备案 |

部署时把整个目录原样上传即可，无需构建步骤。

## 使用说明

- **精准搜索**：输入的整句须完整连续出现；空格隔开多个词表示需同时出现。
- **模糊搜索**：基于相邻两字的倒排索引打分，能容忍错字、漏字和语序变化。
- **补充内容**：保存在浏览器 IndexedDB 里，**只属于当前设备**，换设备不会同步。换设备或清缓存前请在「补充」页导出备份。
- **离线**：首次打开后 Service Worker 会缓存全部内容，之后断网可用。

## 注意事项

- 部署后链接可以公开传播，但**内容需要口令才能看到**；拿到链接的人只能看到解锁界面和密文。
- 用户在手机上新增的补充内容保存在本机 IndexedDB，**不会上传**，也不会被其他人看到。
- 换设备、清理浏览器数据前，记得在「补充」页导出备份。
